# ExxonMobil DataWorks Challenge 2026

## Project purpose

This team project performs reservoir history matching to select 10 production forecasts that best match observed field history. The final output contains quarterly cumulative gas, oil, and water forecasts from Apr 2008 to Jan 2028.

## Repository structure

| Folder/file | Purpose |
| --- | --- |
| `TestCases/` | Original challenge data. Read-only and excluded from Git. |
| `src/` | Reusable Python pipeline code. |
| `data/processed/` | Clean data generated by scripts. Excluded from Git. |
| `outputs/` | Charts and final generated artefacts. Excluded from Git. |
| `tests/` | Automated pipeline tests. |
| `docs/` | Current competition guide, master plan, and role handover documents. |
| `EXCEL_DATA_GUIDE.md` | Description of every supplied workbook. |

## Quick start (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src\person1_data_pipeline.py
python src\person1_data_pipeline.py --with-grid-features
python -m pip install -r requirements-ml.txt
python src\person2_ml_proxy.py
python src\person3_curve_history_ranking.py
python src\person3_history_optimization.py
python src\person4_forecast_backtest.py
python src\person4_forecast_integration.py
python -m pytest -q
```

To include the large, sentinel-safe grid feature extraction, run:

```powershell
python src\person1_data_pipeline.py --with-grid-features
```

The full pipeline reads the original Excel workbooks and creates clean tables, a ranked history-match shortlist, a historical forecast back-test, and a provisional forecast benchmark. The important outputs are:

- `data/processed/person1_case_uncertainties.csv`
- `data/processed/person1_field_history.csv`
- `data/processed/person1_core_cleaning_audit.csv`
- `data/processed/person1_core_source_inventory.csv`
- `data/processed/person1_grid_case_features.csv`
- `data/processed/person3_curve_history_ranking.csv`
- `data/processed/person3_optimized_parameters.csv`
- `data/processed/person4_forecast_backtest_summary.csv`
- `data/processed/person4_final_forecast_long.csv`
- `data/processed/person4_final_forecast_audit.csv`
- `data/processed/person4_template_export_audit.csv`
- `outputs/person3_top_history_matches.png`
- `outputs/person4_forecast_backtest_comparison.png`
- `outputs/person4_delivery/Template Deliverable - provisional forecast.xlsx`

The current export is `outputs/person4_delivery/Template Deliverable - provisional forecast.xlsx`. It is excluded from Git with all generated outputs. It uses the saved Person 2 proxy only for historical contract validation because that artifact is deliberately restricted to 1998-2008; a back-tested rate extrapolation produces the 2008-2028 benchmark. It must be replaced only after the team approves the shortlist and forecast assumptions.

## Team workflow

Work by stage, with a main owner and reviewer. Each handover must include a runnable command, output location, known limitations, and a short code walkthrough. See `docs/01_MASTER_PLAN_AND_TIMELINE.md` for the current plan.

## Data handling

- Never edit files under `TestCases/`.
- Do not commit raw source data, processed data, or final deliverables to Git.
- Keep every cleaning decision documented in the audit files.
- Do not publish challenge materials externally.
- The source production curves end on 1 Jan 2008. The 2008–2028 values are a modelled benchmark, not supplied ground truth; approve its assumptions before final export.
