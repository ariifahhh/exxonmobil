# ExxonMobil DataWorks Challenge 2026

## Project purpose

This team project performs reservoir history matching to select 10 production forecasts that best match observed field history. The final output contains quarterly cumulative gas, oil, and water forecasts from Apr 2008 to Jan 2028.

## Repository structure

| Folder/file | Purpose |

## Quick start (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src\stage1_load_core.py
python src\stage1_clean_curves.py
python src\stage2_history_matching.py
python src\stage3_forecast_backtest.py
python src\stage3_baseline_forecast.py
python -m pytest -q
```

The full pipeline reads the original Excel workbooks and creates clean tables, a ranked history-match shortlist, a historical forecast back-test, and a provisional forecast benchmark. The important outputs are:

- `data/processed/case_uncertainties.csv`
- `data/processed/field_history.csv`
- `data/processed/core_cleaning_audit.csv`
- `data/processed/core_source_inventory.csv`
- `data/processed/case_history_match_ranking.csv`
- `data/processed/forecast_backtest_summary.csv`
- `data/processed/case_forecast_baseline_long.csv`
- `outputs/core_data_before_cleaning.png`
- `outputs/top_history_matches.png`
- `outputs/forecast_backtest_comparison.png`
- `outputs/baseline_forecast_ensemble.png`

The current export is `outputs/person4_delivery/Template Deliverable - provisional forecast.xlsx`. It is excluded from Git with all generated outputs, and must be replaced only after the team approves the shortlist and forecast assumptions.

Open `notebooks/dataworks_workflow.ipynb` in VS Code/Jupyter, select the `.venv` kernel, and use **Run All** to run the entire workflow. This is the team's single notebook for Stages 1–3.

## Team workflow

Work by stage, with a main owner and reviewer. Each handover must include a runnable command, output location, known limitations, and a short code walkthrough. See `CHALLENGE_PLAN.md` for the full plan.

## Data handling

- Never edit files under `TestCases/`.
- Do not commit raw source data, processed data, or final deliverables to Git.
- Keep every cleaning decision documented in the audit files.
- Do not publish challenge materials externally.
- The source production curves end on 1 Jan 2008. The 2008–2028 values are a modelled benchmark, not supplied ground truth; approve its assumptions before final export.
